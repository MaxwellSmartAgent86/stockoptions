tastytrade

Create a client with the read scope only, then a personal grant. This page exchanges that grant for a 15-minute token and reads open positions. The client secret and the refresh token stay in this tab. They are not saved.

  1. On my.tastytrade.com go to Manage, My Profile, API, OAuth Applications, and choose New OAuth client. Use the live site, not the sandbox.
  2. Set the scope to read. Leave trade off. For the redirect, use https://maxwellsmartagent86.github.io/stockoptions/mine.html. This page does not use the redirect.
  3. Copy the client secret before you leave that screen. It is shown once.
  4. Choose Manage, then Create Grant, and copy the refresh token. Two-factor authentication has to be on for a read grant.
