Five answers

My trades

Drop the positions file from the broker. Each set of legs is named as one of the trades on the study page, with the lesson’s reason for that shape. Under that is a best guess for why the shape was opened, from the price, the trend into the open, and how much the stock has been moving. The file does not record the motive. The guess is not a recommendation to place a trade.

Positions file

Use the downloaded positions file, or a saved Tastytrade fill. An account number in the file is left out.

A way to read a position against the lesson. Not a recommendation to place a trade.
